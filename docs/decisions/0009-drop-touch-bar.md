# 0009 – Drop Touch Bar support

- Status: Accepted
- Date: 2026-11-10

## Context
The old app had Touch Bar items for curtains, notes, navigator, next-slide preview, drawing and pointer appearance. Only older MacBook Pro models have a Touch Bar.

## Decision
The new app does not support the Touch Bar (product-owner decision).

## Consequences
Parity item DROP-01 is `dropped`. All Touch Bar functions remain reachable through menus and keyboard shortcuts.
