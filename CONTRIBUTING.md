# Contributing

Thanks for your interest in SlidePilot.

## Before you start
- Open an issue first, so we can agree on the scope.
- The scope of the rewrite is defined in [docs/feature-parity.md](docs/feature-parity.md).
- Everything in this repository is written in English.

## Pull requests
- Branch from `main` and open a pull request against `main`. PRs are squash-merged.
- CI must be green.
- Describe what changed and how to verify it.
