# Timing

SlidePilot offers you multiple options, to keep an overview over your presentation time.

## Clock

A clock with the current time is always displayed on the top left, for you to know what time it is.

## Stopwatch

Next to the clock you have a stopwatch, which counts the time up from 00:00. The stopwatch can be started and stopped using the **S** key or selecting *Moderator* → *Start/Stop Time*. Reset the stopwatch to zero by pressing the **R** key or selecting *Moderator* → *Reset Time*.

## Timer

Alternatively to the stopwatch, you can also use a timer, which counts down the time from a given time. To use the timer, go in the menu *Moderator* → *Mode* → *Timer*. You can specify a starting time by either pressing the **T** key, or go in the menu *Moderator* → *Set Timer*.

The timer can be started and stopped using the **S** key or selecting *Moderator* → *Start/Stop Time*. Reset the timer to the time you initially set it to by pressing the **R** key or selecting *Moderator* → *Reset Time*.
